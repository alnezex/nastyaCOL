# Публикация сайта: GitHub Pages

Сайт раздаёт сам GitHub, сервер не нужен:

```
git push в main  →  GitHub Pages  →  https://alnezex.github.io/nastyaCOL/
```

Через 1–2 минуты после push новая версия открывается по ссылке с любого устройства, сразу по HTTPS.
Бесплатно это работает для публичного репозитория.

## Как включить (один раз)

1. В репозитории откройте **Settings → Pages**.
2. В блоке «Build and deployment»: **Source — Deploy from a branch**.
3. **Branch — `main`**, папка **`/ (root)`** → **Save**.
4. Через минуту-две вверху этой страницы появится ссылка на сайт.

Файл `.nojekyll` в корне говорит GitHub не прогонять сайт через сборщик Jekyll, а отдавать файлы как есть.
Не удаляйте его.

## Как обновлять сайт

```bash
git add .
git commit -m "что поменялось"
git push
```

Ход публикации виден во вкладке **Actions** (запуск «pages build and deployment»):
зелёная галочка — сайт обновлён. Если страница показывает старое, обновите её с Ctrl+F5.

**Откатить неудачное изменение:** `git revert HEAD` и `git push`.

## Что важно знать

- Всё содержимое репозитория доступно по ссылке, в том числе README.md. Не кладите в репозиторий ничего секретного.
- GitHub не принимает файлы больше 100 МБ, а весь сайт должен быть меньше 1 ГБ. Видео для первого экрана лучше сжать до 10–20 МБ.
- Свой домен (например, thelastdisk.ru) подключается там же, в **Settings → Pages → Custom domain**; HTTPS для него GitHub выдаёт бесплатно.
- Раньше сайт выкладывался на свой сервер через GitHub Actions. Та настройка удалена; при необходимости её можно вернуть из истории git (коммит `c4973eb`: `.github/workflows/deploy.yml` и прежний `DEPLOY.md`).
