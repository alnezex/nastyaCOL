# The Last Disk — сайт магазина

Сайт по макетам «Сайт обзор» (главная) и «Вебсайт продолжение, профиль и каталог» (1920px): три страницы — главная, каталог и личный кабинет. Вёрстка, кнопки, корзина, избранное, поиск и всплывающие окна работают.
Анимации (раздел «АНИМАЦИИ» в конце css/style.css): шапка уменьшается при прокрутке, логотип отъезжает к левому краю, а иконки поиска, профиля и корзины — к правому; диски ROCK/POP/METALL выезжают и медленно крутятся, названия «вылезают» из дисков, пластинки And others по очереди выдвигаются из-под первой (всё это повторяется каждый раз, когда блок снова попадает в экран), карточки и окна появляются плавно. Видео и музыку добавим следующим этапом.

## Как открыть

Дважды кликнуть по `index.html`, сайт откроется в браузере. Сборка и установка не нужны.

Для хостинга загрузите папку целиком (`index.html`, `css/`, `js/`, `assets/`) на любой статический хостинг.

Сайт на сервере обновляется автоматически после каждого `git push` в `main`. Как это устроено и как настроить сервер — в [DEPLOY.md](DEPLOY.md).

## Структура

```
index.html          — главная: все блоки и всплывающие окна
catalog.html        — каталог: полки «Винил», «CD», «DVD», фильтры, сортировка, поиск
profile.html        — личный кабинет: профиль, заказы, скидки, корзина, избранное
css/style.css       — общие стили и главная (десктоп + мобильная версия в конце файла)
css/pages.css       — каталог и кабинет
js/products.js      — все товары (название, цена, формат, жанры, картинка)
js/main.js          — общее для всех страниц: корзина, избранное, заказы, окна, поиск, меню, карусель главной
js/catalog.js       — логика каталога
js/profile.js       — логика кабинета
assets/img/         — картинки из макетов (переименованы латиницей)
```

## Как править

**Добавить или изменить товар.** Откройте `js/products.js` и скопируйте любой объект.
Поле `format` (`vinyl`, `cd`, `dvd`) решает, на какой полке каталога лежит товар; порядок в файле — порядок в каталоге.
В карусель на главной попадают только товары с полем `popular` (число — место в карусели).
Каждая полка каталога показывает 8 карточек, кнопка «листать дальше» появляется сама, когда товаров больше.
Цена `0` показывается как `FREE!`. Перенос строки в имени исполнителя ставится через `\n`.

**Сдвинуть элемент.** В `css/style.css` все размеры указаны в пикселях макета (холст 1920px):
`calc(212 * var(--u))` означает «212px по макету». У картинок координаты заданы переменными:

```css
.genre-disc--rock { --x: 212; --y: 1039; --w: 722; }  /* левый край, верх, ширина */
```

На любом мониторе композиция пропорционально масштабируется. Уже 900px включается мобильная раскладка.

**Видео в первом экране.** Положите файл в `assets/video/hero.mp4` и раскомментируйте
строку `<video ...>` в блоке HERO в `index.html`.

**Музыка на дисках ROCK / POP / METALL.** При наведении мышки на диск играет случайная песня жанра
с нужной секунды, когда мышку убирают — музыка затихает. Список песен, имена файлов и секунда старта
лежат в начале `js/music.js`. Сами mp3 нужно положить в `assets/audio/rock/`, `assets/audio/pop/`
и `assets/audio/metal/` под именами из этого списка (например, `assets/audio/rock/in-the-end.mp3`).
Песни без файла пропускаются, так что их можно добавлять постепенно.
Браузеры разрешают сайту включать звук только после первого клика или касания на странице,
поэтому до первого клика наведение молчит (сайт один раз об этом подсказывает). На телефонах наведения нет, там музыка не играет.

## Что как работает

| Элемент | Действие |
|---|---|
| ABOUT / SHOP / CONTACT | прокрутка к разделам «О нас», карусели, подвалу (с других страниц — переход на главную) |
| CATALOG, В КАТАЛОГ, VIEW ALL, AND OTHERS | страница каталога |
| VINYL, CD ДИСК, ссылки «Каталог» в подвале | нужная полка каталога |
| Лупа в шапке | на главной раскрывает поиск, на других страницах ставит курсор в строку поиска |
| Поиск на главной | кнопка ПОИСК в правом нижнем углу экрана: по нажатию поле выезжает влево, после поиска сворачивается обратно; при прокрутке кнопка полупрозрачная |
| Поиск | ищет по названию, исполнителю, жанру и формату: на главной — в карусели, в каталоге — по полкам, из кабинета ведёт в каталог |
| Диски ROCK / POP / METALL | наведение — музыка жанра, нажатие — фильтр карусели по жанру |
| Глаз в кабинете | поворачивается зрачком за курсором |
| Кнопки ROCK / HIP-HOP / … | фильтр карусели по жанру |
| Стрелки карусели | листают по одной карточке, с края переходят в начало или конец |
| ФИЛЬТРЫ / ПО УМОЛЧАНИЮ в каталоге | фильтр по жанрам и сортировка — общие для всех полок |
| Вкладки ВИНИЛ / CD / DVD | переход к нужной полке |
| Обложка в каталоге или в карусели | окно товара; товар попадает в «Недавно смотрели» |
| Сердечко | добавляет в избранное или убирает из него |
| В КОРЗИНУ | добавляет товар; повторное нажатие открывает корзину |
| Корзина | количество, удаление, итог, форма заказа; содержимое сохраняется в браузере, оформленный заказ появляется в «Моих заказах» |
| Иконка профиля | личный кабинет: КАБИНЕТ (профиль и «Мои заказы»), ИЗБРАННОЕ; КОРЗИНА открывает то же окно корзины, что и иконка в шапке |
| Доставка, Услуги, Акции, «Для подарка», Оферта, Политика | всплывающие окна (закрываются крестиком, кликом по фону или Esc) |

## Что пока заглушка

- Тексты в окнах «Доставка», «Услуги», «Акции», «Для подарка», «Оферта», «Политика»
  написаны как пример. Их нужно заменить настоящими.
- Окна корзины и товара, выпадающие фильтры, список заказов и мобильная версия каталога и кабинета
  оформлены в стиле сайта сами (в макетах их не было).
- Заказ пока **никуда не отправляется**: нужен сервер или сервис форм. Входа в кабинет нет:
  избранное, заказы и телефон хранятся в браузере покупателя.
- Скидка 50% на первый заказ только написана в кабинете, к сумме корзины она не применяется.
- Жанра JAZZ и «Аксессуаров» пока нет среди товаров: для джаза на главной показывается «Скоро в продаже»,
  ссылка «Аксессуары» в подвале показывает уведомление.
- Обложки CD, DVD и двух новых пластинок вырезаны из карточек макета, поэтому они небольшого размера.
  Для чёткости их лучше заменить исходниками.
- Шрифт Bebas Neue Bold (с кириллицей) подключается с fonts.cdnfonts.com, Michroma — с Google Fonts.
  Palatino Linotype и Myriad Pro берутся из системы (на Windows Palatino есть, Myriad заменяется похожим).
  Перед запуском сайта шрифты лучше положить в проект.
