# The Last Disk — сайт магазина

Одностраничный сайт по макету «Сайт обзор» (1920px). Вёрстка, кнопки, корзина, поиск и всплывающие окна работают.
Анимации (раздел «АНИМАЦИИ» в конце css/style.css): шапка уменьшается при прокрутке, логотип отъезжает к левому краю, а иконки поиска, профиля и корзины — к правому; диски ROCK/POP/METALL выезжают и медленно крутятся, названия «вылезают» из дисков, пластинки And others по очереди выдвигаются из-под первой (всё это повторяется каждый раз, когда блок снова попадает в экран), карточки и окна появляются плавно. Видео и музыку добавим следующим этапом.

## Как открыть

Дважды кликнуть по `index.html`, сайт откроется в браузере. Сборка и установка не нужны.

Для хостинга загрузите папку целиком (`index.html`, `css/`, `js/`, `assets/`) на любой статический хостинг.

Сайт на сервере обновляется автоматически после каждого `git push` в `main`. Как это устроено и как настроить сервер — в [DEPLOY.md](DEPLOY.md).

## Структура

```
index.html          — разметка всех блоков страницы и всплывающих окон
css/style.css       — стили (десктоп + мобильная версия в конце файла)
js/products.js      — список альбомов для карусели (название, цена, жанр, картинка)
js/main.js          — логика: карусель, фильтры, поиск, корзина, окна, мобильное меню
assets/img/         — картинки из макета (переименованы латиницей)
```

## Как править

**Добавить или изменить альбом.** Откройте `js/products.js` и скопируйте любой объект.
Цена `0` показывается как `FREE!`. Перенос строки в имени исполнителя ставится через `\n`.

**Сдвинуть элемент.** В `css/style.css` все размеры указаны в пикселях макета (холст 1920px):
`calc(212 * var(--u))` означает «212px по макету». У картинок координаты заданы переменными:

```css
.genre-disc--rock { --x: 212; --y: 1039; --w: 722; }  /* левый край, верх, ширина */
```

На любом мониторе композиция пропорционально масштабируется. Уже 900px включается мобильная раскладка.

**Видео в первом экране.** Положите файл в `assets/video/hero.mp4` и раскомментируйте
строку `<video ...>` в блоке HERO в `index.html`.

## Что как работает

| Элемент | Действие |
|---|---|
| ABOUT / SHOP / CATALOG / CONTACT | прокрутка к разделам «О нас», карусели, каталогу, подвалу |
| Лупа в шапке | возвращает к строке поиска и ставит в неё курсор |
| Поиск | ищет по названию, исполнителю, жанру и формату и показывает результат в карусели |
| Кнопки ROCK / HIP-HOP / … и диски ROCK / POP / METALL | фильтр карусели по жанру |
| VINYL, CD ДИСК, ссылки «Каталог» в подвале | фильтр по формату |
| В КАТАЛОГ, AND OTHERS, VIEW ALL | показать все альбомы |
| Стрелки карусели | листают по одной карточке, с края переходят в начало или конец |
| В КОРЗИНУ | добавляет альбом; повторное нажатие открывает корзину |
| Корзина | количество, удаление, итог, форма заказа; содержимое сохраняется в браузере |
| Профиль, Доставка, Услуги, Акции, «Для подарка», Оферта, Политика | всплывающие окна (закрываются крестиком, кликом по фону или Esc) |

## Что пока заглушка

- Тексты в окнах «Доставка», «Услуги», «Акции», «Для подарка», «Оферта», «Политика»
  написаны как пример. Их нужно заменить настоящими.
- Окна корзины и входа в кабинет оформлены в стиле сайта сами (в макете их не было).
- Заказ и вход пока **никуда не отправляются**: нужен сервер или сервис форм.
- Жанров HIP-HOP, ELECTRONIC, RAP, JAZZ и форматов DVD и «Аксессуары» пока нет среди товаров,
  поэтому для них показывается «Скоро в продаже».
- Шрифт Bebas Neue Bold (с кириллицей) подключается с fonts.cdnfonts.com, Michroma — с Google Fonts.
  Palatino Linotype и Myriad Pro берутся из системы (на Windows Palatino есть, Myriad заменяется похожим).
  Перед запуском сайта шрифты лучше положить в проект.
